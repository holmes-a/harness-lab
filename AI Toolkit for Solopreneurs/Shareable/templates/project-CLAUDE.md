|---|---|

| `_assets/` | Project-specific files and reference material |
| `_ai/task-prds/` | Detailed PRDs, briefs, and captured items requiring more than two lines of context |
| `_skills/` | Project-scoped skills — created via `/new-skill`; empty at project creation |

## Entry Standards
**decisions.md:** Date · Decision (1 sentence) · Rationale (1 sentence) · Finding ref · Supersedes ref
**findings.md:** Date · Finding (1 sentence) · Source · Status (Open/Actioned/Superseded) · Decision ref
**facts/:** One-liner in `## Facts` → full detail in `_ai/facts/[topic].md`. Graduated by `/project-wrap-up` — always confirm with user before editing this file.
**tasks.md:** Append `[blocked by: X]` to flag a dependency. Append `→ [PRD](_ai/task-prds/filename.md)` where a detailed PRD exists. `## Inbox` holds items captured mid-session via /grilling-handoff — `[task]`, `[finding]`, `[decision]`, `[thought]` entries awaiting triage at next session start.
**acceptance.md:** Four sections — Structure (required output sections, in order), Must (assertions), Never (prohibitions), Data (joins, filters, input and output paths) — plus a `## Human gate` listing judgements deliberately left uncheckable. Every entry must be verifiable by reading the artifact and its sources; "tone should be warm" belongs under Human gate, not Must.
