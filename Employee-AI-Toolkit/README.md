# Employee AI Toolkit

Personal discovery project to evaluate and refine an AI toolkit for Saturn employees, through hands-on use and iteration. Builds the evidence base for a future board-level adoption decision.

## Folder Contents
- `CLAUDE.md` — project context for AI sessions
- `tasks.md` — active task list
- `session-notes/` — per-session AI notes (YYYY-MM-DD.md)
- `assets/` — shareable deliverables: skills, context templates, onboarding guides, and resources for the eventual `init-ai-toolkit` skill
