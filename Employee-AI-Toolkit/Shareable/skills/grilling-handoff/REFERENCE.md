# Grilling Handoff — Reference

## Context File Template

Use this structure when the captured item needs more than two lines of context:

```markdown
# Inbox: [Item — one sentence]

**Type:** [task / finding / decision / thought]  
**Captured:** YYYY-MM-DD

## Why
[The reasoning behind this item — why it matters, what problem it solves]

## What
[What needs to happen or what was observed — concrete and specific]

## Resolution (if known)
[What a good outcome looks like, if clear from the conversation. Omit this section if unknown.]
```

File naming: `task-prds/inbox-YYYY-MM-DD-[slug].md`
