# Project Migrate — Reference

## Content Mapping Rules

Use during Step 3 to route existing content to the correct scaffold destination.

| Source content | Destination |
|---|---|
| Existing decisions, key choices, settled architecture | `_ai/decisions.md` (standard projects only) |
| Handoff notes, in-progress state, status files | `_ai/tasks.md` — current-state line and open task list |
| Analysis, observations, test results, reports | `_ai/findings.md` (standard projects only) |
| Tech stack, architecture, design notes | `## Brief`, `## Tech Stack` (Developer), or `## Key Constraints` as appropriate |
| Remaining content that doesn't clearly map | Flag to user — ask where it should go before writing |
